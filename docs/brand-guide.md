# Identidade visual do Nexus Finance

Este guia mantém a marca consistente no aplicativo, no GitHub e em materiais de apresentação.

## Conceito

O símbolo combina três ideias:

- o monograma `NF`, identificando o produto;
- barras crescentes, representando acompanhamento e evolução financeira;
- uma linha de conexão, representando a integração entre dados, decisões e objetivos.

## Paleta principal

| Papel | Cor | Uso recomendado |
|---|---|---|
| Verde Nexus | `#00BFA6` | marca, destaques e ações principais |
| Receita | `#3DDC97` | valores positivos e entradas |
| Despesa | `#FF6B6B` | valores negativos e saídas |
| Fundo escuro | `#0B0F12` | fundo principal do aplicativo |
| Superfície | `#10161A` | cartões e navegação |
| Superfície elevada | `#161D22` | componentes com maior destaque |

Os valores acima correspondem aos tokens definidos no design system do aplicativo.

## Aplicações

### Ícone do aplicativo

- usar apenas o símbolo, sem o texto `NEXUS FINANCE`;
- preservar a área de respiro em torno da marca;
- não adicionar bordas ou elementos financeiros extras;
- deixar o sistema operacional aplicar o formato final do ícone.

### Splash screen

- centralizar o símbolo no fundo escuro;
- evitar textos pequenos, animações longas ou informações adicionais;
- manter a passagem para o Dashboard visualmente contínua.

### Interface

- aplicar o símbolo sem criar uma segunda moldura ao redor do ícone;
- priorizar legibilidade em tamanhos reduzidos;
- usar o verde da marca com moderação para manter a hierarquia visual.

## Arquivo principal

O arquivo-fonte utilizado pelo aplicativo está em:

`assets/branding/nexus_app_icon.png`
